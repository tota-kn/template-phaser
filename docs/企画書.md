# 企画書：自分を撃って進むアクションパズル（仮）

## コンセプト

操作は「自分を大砲の弾のように撃ち出す」ことだけ。
単純な操作の中に、使い道の違いや地形との組み合わせが隠れていて、プレイヤーが遊びながら「こんなこともできるのか」と気づいていくゲーム。

- ジャンル：アクション寄りのアクションパズル（1画面ごとに解き方を考え、操作で実現する）
- 参考作品：Celeste（1つの操作の多用途化）、ElecHead（操作にリスクが伴う）、VVVVVV（移動手段の強い制約）、タッチ！カービィ（ミッションによるやり込み）

### 設計の軸

- **動詞は「撃つ」一つ。** 新しい操作を足すのではなく、既存の操作の別の使い道に気づかせる。
- **操作にはコストがある。** 溜めるほど強いが、その間に落ちる・転がる。
- **ルールは一貫させる。** 例外を作らない。発見の快感は「最初から知っていたはずなのに」という感覚から来る。

---

## 基本仕様

### 移動

- 歩行・ジャンプはできない。移動は「自分を撃つ」ことと「転がり」のみ。
- 発射方向は8方向。
- 発射の強さは4段階。

| 段階 | 入力 | 主な用途 |
|---|---|---|
| 0 | タップ | 微調整、ブレーキ |
| 弱 | 長押し（短） | 敵に乗る、コレクション回収 |
| 中 | 長押し（中） | 通常移動、強と弱の間の調整 |
| 強 | 長押し（長） | 遠距離移動、破壊 |

- 段階が上がる瞬間に音・光で知らせる。
- 軌道の予測線は表示しない。

### 溜め

- 溜めている間も重力で落ちる（空中）、転がり続ける（地上）。
- 溜めること自体が縦方向・横方向の移動手段にもなる。

### 地上と空中

- 地上（転がり中を含む）では何度でも撃てる。
- 空中で撃つには「空中発射ストック」が必要。
- 空中発射は速度を**置き換える**（加算しない）。

### 空中発射ストック

- 一定以上の速度で何かを壊すと、ストックを1つ得る。地上で壊しても得られる。
- 最大1個。使うまで保持する。持っている状態で壊しても増えない。
- ストックを持っている間はキャラの色が変わる。

### 0溜め

- 撃つと速度がほぼゼロに置き換わり、その場で止まる（地上・空中どちらでも同じ理屈で働く）。
- 連続では使えない（待ち時間あり）。連打による実質的な歩行や、坂で止まり続けることを防ぐ。
- 待ち時間中は見た目の変化や不発音で知らせる。

### 転がり

- 転がり中は地上扱い。
- 平地では摩擦で減速して止まる。
- 坂では転がり続け、止まり続けることはできない。
- 一定速度以下で強制停止（谷底での往復を防ぐ）。
- 挙動は物理演算任せにせず、単純で予測しやすい規則で作る。

### 破壊判定

- **速度**が一定以上で当たると壊せる。発射の段階ではなく速度で判定する。
- 強発射だけでなく、高所からの落下や坂での加速でも壊せる。
- 壊せる速度に達している間はキャラが光る・軌跡が出るなど、判定を推測できる表示を出す。

### 敵

- 壊せる速度で当たる → 倒せる。空中発射ストックを得る。
- 弱い速度で当たる → 上に乗れる。乗っている間は地上扱い。動く敵なら運んでもらえる。
- 「倒して空中発射を得るか、乗って足場と移動を得るか」の選択を作る。

### コレクションアイテム

- 弱い速度で触れると回収できる。
- 速すぎると壊れてしまう（同じ破壊判定ルール）。

### リトライ

- 1画面単位。失敗したら即その画面の最初から。
- 敵・ブロックは画面のリトライで元に戻る（壊し方を誤って詰むことを防ぐ）。
- 予測線がないため、リトライの速さは必須要件。

## ギミック候補

| ギミック | 内容 | 生まれる発見 |
|---|---|---|
| 硬い壁 | 跳ね返る | 反射で裏側を狙う |
| 柔らかい壁 | めり込んで止まる | そこを次の発射地点にする |
| 脆いブロック | 一定速度以上で壊れる | 弱く撃てば乗れる・強く撃てば壊せる |
| 坂 | 転がって加速する | 溜め無しで壊せる速度に達する |
| 氷の床 | 止まらない | 0溜めでブレーキをかける |
| 粘着床 | 転がらない | 確実に止まれる足場 |
| 半円の窪み | 往復して勢いを溜める | 勢いを利用して脱出・破壊 |
| 固定大砲 | 入ると決まった方向へ自動発射 | エネルギー不要の移動 |
| バネ・送風 | 押し出す・軌道を曲げる | エネルギー不要の移動、狙いの補正 |
| 動く敵 | 乗ると運ばれる | 移動する足場から撃つ |
| スイッチ | 通過で押せる | 1回の発射で複数を押す |

## 想定される「気づき」

序盤で意識的に配置し、技術だけでなくルール側の発見を体験させる。

- 溜めて落ちることが、縦方向の移動になる
- 弱で敵に当てると乗れる
- 空中で0溜めを撃つと止まれる
- 置き換え式なので、落下の勢いがついていても撃てば狙い直せる
- 高所から落ちれば、弱い発射でも壊せる
- 坂で加速すれば、溜めなくても壊せる
- 飛び出す前に地上で壊しておけば、空中発射を持って出られる
- 崖の手前で溜め始めれば、空中から撃てる（仮仕様が採用された場合）

## ミッション（クリア後のやり込み）

本編には回数・エネルギーの制限をかけない（試行錯誤を萎縮させないため）。

### タイムアタック

- 強で一気に進む解き方が有利。

### エネルギー節約

- 発射ごとにコストを数える。0＝0、弱＝1、中＝2、強＝3。
- 転がり・固定大砲・敵に乗るなど、エネルギー不要の移動をどれだけ使えるかが鍵。
- タイムアタックとは逆方向の解き方を求める。

### ステージ設計への影響

- 各画面に「速いが高コスト」「遅いが低コスト」の2ルート程度を用意する。
- 本編のステージを作る時点で、その画面の節約ルートをメモしておく。

## 試作の順番

1. 何もない空間で、8方向×4段階の発射・落下・溜め中の落下の手触り
   - 「撃って飛ぶこと自体が気持ちいいか」を確かめる。ここが楽しくなければギミックを足しても挽回は難しい。
   - 溜め時間（特に強までの時間）が最も詰めるべき数値。
2. 坂・平地での転がりと0溜めのブレーキ
3. 速度判定での破壊と空中発射ストック
4. 敵（倒す・乗る）
5. ギミックとステージ
6. ミッション

---

## 注意点

- **状態の可視化を丁寧に。** 予測線を出さない分、溜め段階・ストック・破壊可能速度・0溜めの待ち時間はすべて見てわかるようにする。
- **ギミックを増やしすぎない。** 新要素を足す前に、既存の要素の組み合わせで作れないか検討する。
- **アクション寄りになると発見が技術に偏りやすい。** ルール側の気づきを序盤に配置する。

## プロトタイプ（試作1〜3の範囲＋α）

`pnpm dev` で起動。3つの部屋で、発射・溜め・転がり・破壊・ストック・敵・床の種類・固定大砲を試せる。

- 操作：方向キー/WASDで向き（8方向）、Space/Zの長押しで溜め、離して発射。マウス・タッチは押している間溜め、指の方向へ飛ぶ。R＝やり直し、N/P＝部屋切替。
- 調整用の数値は `src/game/config.ts` に集約（重力、摩擦、破壊速度、各段階の溜め時間と初速、0溜めの待ち時間など）。
- 部屋は `src/game/levels.ts` に多角形で定義。
- 物理と状態は `src/game/world.ts`（Phaser非依存）。描画と入力は `src/scenes/Game.ts`。
- 未決事項のうち、猶予時間（100ms）と溜め開始時点での判定は仮置きのまま実装済み。最大まで溜めた後は保持し続ける。
