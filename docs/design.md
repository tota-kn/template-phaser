# 推理アクション試作「鉄甲の番人」設計メモ

Claude Code への引き継ぎ用。設計の経緯・決定事項・未決事項・現状の実装をまとめる。

## コンセプト

推理要素を前面に出した横スクロールアクション。ロックマンの弱点武器のように「様々な選択肢から勝ち筋を見つける」ことを、総当たりではなく推理で行わせたい。

## 決定事項（ユーザーの意向）

- **戦闘が主軸。** ステージ攻略は入れない（入れるとゼルダやアクションパズルになるため）。
- **戦闘外で手がかりを集め、戦闘で検証する。** ただし戦闘前に答えが確定すると戦闘が作業になるので、戦闘外の手がかりは候補を絞る程度にとどめ、決め手は戦闘中の観察で得る方針。
- **持ち込み武器は3枠。** 枠の制限で「どれを選ぶか」自体を推理の答えにする（Cuphead の装備選択に近い）。
- **戦闘を繰り返して情報を得ていく。** 敗北・撤退でも観察記録が増え、それが次の挑戦の手がかりになる。
- **ゲームパッド対応。** キーボードと併用。

## 設計上の論点（議論済み、要検証）

1. **総当たり対策。** 何度でも挑めるなら、8種から3つ持ち込みでも3回で全武器を試せる。対策として「単体で当てても効かない、状態の組み合わせ（順序）でのみ効く」条件にしている。組み合わせは順序付き3手で 8×7×6 = 336 通り。
2. **フィードバックの粒度。** 詳しいほど推理しやすいが、総当たり（マスターマインド的な絞り込み）も楽になる。現状は「理由が見える反応」（灼熱で赤くなる、ひびが入るなど）を採用。
3. **推理は必須か任意か。** 現状は「酸だけが装甲越しに微ダメージ」という、遅いが一応勝てるルートを残している（任意寄り）。
4. **推理と暗記の区別。** 繰り返し戦闘で得るものが行動パターンの暗記だけだと、普通の高難度アクションになる。観察記録は論理的に組み合わせて使う情報であるべき。
5. **アクションの腕前を情報収集能力にする。** 状態には制限時間があり、灼熱中に氷を当てるなど、武器切替と命中のタイミングが要る。

## 別案（未着手）: ÖOO 的な「道具の新しい使い方」

特定の組み合わせでしか攻撃が通らない、アクションパズル寄りのボス戦。ユーザーは ÖOO のように「道具の新しい使い方に気づく」体験もさせたい。

- 推理（手がかりから論理的に答えを出す）とは別の、ひらめき寄りの楽しさ。
- 武器を3〜4種に絞り、1つの武器に複数の性質を持たせるほうが合う（例: 炎は攻撃・氷を溶かす・照らす・鉄球を熱する、鉄球は投擲・足場になる・熱球になる）。8種から3つ選ぶ現行案とは相性が悪い。
- 後出しの隠しルールではなく、すでに見せた性質の組み合わせで解けること。
- ひらめきには考える時間が要るので、ボスの攻撃が止まる隙や、戦闘前に性質を体験させる場が必要。

進め方の合意: まず現行案（推理寄り）で遊べる状態にし、総当たりされるかを確かめてから別案を試して比較する。

## 現状の実装（ネタバレ注意）

### ボスのルール（`src/data/boss.ts`）

装甲状態: `armor`（通常）→ `heated`（灼熱 4秒）→ `cracked`（ひび割れ 5秒）→ `core`（核露出 7秒）→ 時間切れで `armor` に戻る。

- 正解手順: 炎で灼熱 → 灼熱中に氷でひび割れ → ひび割れ中に鉄球で装甲破壊 → 核に攻撃（雷以外 3 ダメージ）
- 雷: 常に吸収されボスが 5 回復する（罠）
- 酸: 装甲越しに 1 ダメージ（総当たり用の遅いルート）
- 閃光: ボスを 1.2 秒怯ませる（攻撃が止まる）
- 音波: ダメージなし。内部に何かあることを示唆する観察が得られる
- 矢: 装甲には弾かれる
- ボス HP 100、プレイヤー HP 5

### 証言（戦闘前から読める手がかり）

- 村の老人: 雷の夜ほど元気になる → 雷は吸収
- 鍛冶屋: 灼けた鋼に水をかけると割れる → 炎 → 氷
- 古文書: 鎧は打ち砕けないが、傷を負えば別 → ひび割れ中に鉄球

### 観察記録

武器 × 装甲状態ごとの反応文を `resolveHit` が返し、初めて見た文が記録される（全 21 種）。挑戦履歴（持ち込み・結果・新発見数）と合わせて localStorage に保存。準備画面に表示され、総当たりされているかの確認に使える。

### ボスの攻撃

- 3 方向の狙い撃ち弾（通常 1.6 秒、HP 半分以下で 1.1 秒間隔）
- 予備動作「！」のあと地面を這う衝撃波（ジャンプで回避）

## 既知の課題・調整候補

- 鉄球は放物線で射程が短く、ボスに近づかないと当たらない（意図的だが要確認）
- 核露出 7 秒中の火力が高すぎる／低すぎるかは未調整
- 証言の鍛冶屋の手がかりが直接的すぎる可能性
- スマホ（タッチ）操作は未対応。テンプレートはスマホ前提だがキーボード／パッドのみ
- グラフィックはすべて Preloader で生成した仮の図形

## 次のステップ候補
